#+title: Folio

A web application for viewing, navigating and annotating PDF music scores
in a browser (designed with the iPad and Apple Pencil in mind). FastAPI
backend, plain JS front end.

Main features: Fit / Wide / 2-up display modes; pen, text and eraser
annotations with undo; composer/title/tag search; start-page stamps;
setlists (including nested setlists) with playback; content-hash identity
so renamed or moved PDFs keep their annotations and setlist entries.

The full feature list and run instructions are in [[file:README.md][README.md]].
