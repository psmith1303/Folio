#+TITLE: Folio — Manual Test Checklist
#+DATE: 2026-03-20
#+STARTUP: showall

* Library
- [ ] Set Folder — enter your music library path, scores populate
- [ ] Search — type a composer or title, results filter live
- [ ] Composer dropdown — filters to one composer
- [ ] Tag chips — click to filter by folder tags
- [ ] Column sort — click Composer/Title/Tags headers
- [ ] =.exclude= — put a =.exclude= file in a subdirectory, rescan, verify it's hidden

* Score Viewer
- [ ] Open a score — click a row, PDF renders in Fit mode (single page)
- [ ] Page navigation — arrow keys, Space, click right/left half, swipe on touch
- [ ] Wide mode — click "Wide" button, page fills width, scroll vertically; click/swipe navigation disabled; arrow up/down/space scroll natively
- [ ] Wide fullscreen — enter fullscreen in wide mode; scroll past bottom triggers next page, scroll past top triggers previous
- [ ] Auto 2-up — on a wide screen with portrait PDF, 2-up should engage automatically without shrinking the page; on a narrow screen it should stay in Fit
- [ ] Manual 2-up — click "2-up" button, verify it forces side-by-side; click "Fit" to go back
- [ ] Resize — drag browser window wider/narrower; 2-up should toggle based on whether pages would shrink
- [ ] Pen tool — draw ink strokes, change colour and size
- [ ] Text tool — place text, try symbol buttons (dynamics, notes)
- [ ] Eraser — click on an annotation to remove it
- [ ] Clear Page — toolbar button erases all annotations on the current page after confirmation; Undo restores them
- [ ] Pencil-only toggle — on iPad with Apple Pencil, enable; finger drawing is ignored on the pen tool while erase/text/nav still work with finger; setting persists across reloads (localStorage)
- [ ] Undo — Ctrl+Z
- [ ] Rotation — =r= / =R= keys, or ↶/↷ buttons; annotations should stay aligned
- [ ] Intrinsic rotation — open a PDF with a non-zero ~/Rotate~ in its metadata (e.g. some scanner output); verify it appears the same way up as in Acrobat, with no manual rotation needed
- [ ] Fullscreen — press =f= or click Fullscreen button; topbar and toolbar hide; press =f= again to exit
- [ ] Add to setlist — press =s= while viewing a score, pick a setlist
- [ ] Back — Escape or Back button returns to library

* Start page stamp
- [ ] Place — open a score, click "Start", tap a page; the red START stamp appears where tapped, at ~20mm whatever the zoom; the tool drops back to Nav
- [ ] Cursor — on desktop the cursor shows the stamp while placing; clicking "Start" again (or off the page) cancels
- [ ] One per score — place it on page 3, then on page 5; page 3's stamp is gone. Undo on page 5 removes the new one; undo on page 3 brings the old one back
- [ ] Erase / Move — the eraser removes it; the Move tool drags it; rotated pages keep it upright and aligned
- [ ] Opens on the stamp — close and reopen the score from Library, Recent and Newest; each opens on the stamped page. With no stamp, page 1
- [ ] 2-up — opening a stamped score in 2-up shows the stamped page on the left
- [ ] Setlist, default start — a song with start page 1 and a stamp on page 3 opens on page 3; pressing back on page 3 goes to the previous song; coming back from the next song lands on this song's last page
- [ ] Setlist, explicit start — set the song's start page to 2; it opens on page 2 and ignores the stamp; the setlist ▷ button does the same
- [ ] Offline — with the app cached, go offline and reopen a stamped score; the stamp still draws

* Tag editing (regression: tags were silently destroyed, v2.9.3)
- [ ] From the library — open a tagged score, press the edit-tags key, confirm existing chips show; add one, Save; filename keeps the old tags plus the new one
- [ ] From Recent — open the SAME score via the Recent list, edit tags; existing chips must still show (they used to come up empty)
- [ ] From a setlist — open the score via a setlist, edit tags; existing chips must still show
- [ ] Save from Recent or setlist — add a tag and Save; every previously existing tag must survive in the filename
- [ ] Folder tags stay locked — chips from the containing folder show greyed and cannot be removed
- [ ] Unresolvable score — with the server stopped mid-session, press edit-tags; a message appears and the dialog does NOT open empty
- [ ] Cancel after a save — save tags once, reopen the editor, remove a chip, press Cancel; the filename must be unchanged (Cancel must never behave like Save)
- [ ] Shortcuts blocked — with the tag editor open, press arrow/space keys; the PDF behind must NOT turn pages
- [ ] Tag edit during setlist playback — play a setlist, edit tags on a middle song and Save, advance a song then come back; the renamed song must still load
- [ ] Score changed mid-edit — open the editor from a setlist, and if the score behind it changes, Save reports that nothing was saved rather than renaming the wrong file

* Multi-user conflict
- [ ] Open the same score in two browser tabs
- [ ] Draw an annotation in tab A, wait for it to save
- [ ] Draw an annotation in tab B — a "Annotation Conflict" dialog should appear
- [ ] Click "Reload" — tab B reloads with tab A's annotations
- [ ] Repeat, but click "Save anyway" — tab B's version overwrites

* Setlists
- [ ] Switch to Setlists view — click "Setlists" in topbar
- [ ] Create a setlist — New Setlist button, enter name
- [ ] Add songs — Add Song, search, select, set page range
- [ ] Add setlist reference — Add Setlist, pick another setlist; verify it appears as italic row with song count
- [ ] Nested playback — play a setlist containing a sub-setlist; songs from the sub-setlist should play inline
- [ ] Dangling reference — delete a referenced sub-setlist; parent should show "(missing)" for that ref
- [ ] Circular reference — try to add A as sub-setlist of B when B is already in A; should be rejected
- [ ] List view counts — setlists with sub-setlists should show e.g. "2 (5 songs)" in the Songs column
- [ ] Reorder — ↑/↓ buttons in song list, or drag-and-drop; works for both songs and setlist refs
- [ ] Play — click Play, verify page constraints and song auto-advance
- [ ] Rename / Delete — rename a referenced setlist; verify parent's reference updates
- [ ] Back navigation — from setlist detail back to list, from viewer back to setlist detail

* Theme & PWA
- [ ] Theme toggle — click Light/Dark button, verify it persists on reload
- [ ] PWA — on iPad, Add to Home Screen, verify standalone mode
- [ ] Offline — after first load, kill the server; the app shell should still load from service worker cache
